# TFI - SaaS para Gestión de Servicios Técnicos

## Descripción

Plataforma web SaaS multi-organización orientada a pequeños y medianos servicios técnicos.

El sistema busca centralizar y mejorar la trazabilidad del ciclo de reparación,
desde la recepción del equipo hasta su entrega.
